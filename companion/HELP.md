## StreamPulse

Controls a running [StreamPulse](https://github.com/jarbochov/StreamPulse) server.

**Config:** host and port of the StreamPulse server (default `localhost:3000`).

**Actions:** restart or stop the StreamPulse server (Companion can't start it again, so use a shell script such as `start-streampulse.sh` for that), timer control (start, pause, resume, reset, add or subtract time, overlay visibility), goal reset and enable, alert queue (skip, pause, resume, clear), fire a test alert for a rule, enable, disable or toggle a page of a multi-page overlay, show a page, next, previous, first, last and auto-advance, slideshow next, previous, play, pause and toggle, show, hide or toggle any whole overlay (credits, goals, timers, music, custom overlays), music overlay show, hide or toggle, pin the last chat message, mark a clip moment, replay the last alert, start or end a session, change a counter (increment, decrement, reset) or set a variable. Variables and counters created in StreamPulse's Chat Bot page appear as Companion variables `var_<name>`. Any StreamPulse placeholder (for example `chatter.top`, `latest.follower`, `game.name`) can be exposed by listing it, comma separated, in the **Placeholders to expose** config field. Each appears as `ph_<name>`, for example `ph_chatter_top`.

**Feedbacks:** StreamPulse server running (use Invert to flag when it is down), timer state, Twitch live, session phase, goal complete or enabled, alert queue paused, music playing, overlay shown, music overlay visible, slideshow playing, paused or open, overlay page enabled, showing now, and auto-advance on.

**Variables:** server online, uptime and start time, session phase, viewers, stream title and category, now-playing track, alert queue, plus per-timer time and state and per-goal percent and progress, the current page of each multi-page overlay, slideshow position and state, uptime, game details, music position, chat counts, and the latest follower, sub, gift, cheer, donation and raider (with cheer and donation amounts and raid viewer count). Also last chatter and top chatter for the last 5/10/15/30/60 minutes, top hashtags, game developer and rating, clip candidates waiting, session and lifetime followers, subscribers, gift subs, bits and donations, Game Plan (playing now, next scheduled, counts) and weather (temperature, condition, icon, high/low, wind; needs weather enabled in StreamPulse). Slideshow state needs the overlay open in OBS or a browser. Timers and goals appear automatically.
