## StreamPulse

Controls a running [StreamPulse](https://github.com/jarbochov/StreamPulse) server.

**Config:** host and port of the StreamPulse server (default `localhost:3000`).

**Actions:** timer control (start, pause, resume, reset, add or subtract time, overlay visibility), goal reset and enable, alert queue (skip, pause, resume, clear), fire a test alert for a rule, end the session.

**Feedbacks:** timer state, Twitch live, session phase, goal complete or enabled, alert queue paused, music playing.

**Variables:** session phase, viewers, stream title and category, now-playing track, alert queue, plus per-timer time and state and per-goal percent and progress. Timers and goals appear automatically.
