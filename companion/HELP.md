## StreamPulse

Controls a running [StreamPulse](https://github.com/jarbochov/StreamPulse) server.

**Config:** host and port of the StreamPulse server (default `localhost:3000`).

**Actions:** timer control (start, pause, resume, reset, add or subtract time, overlay visibility), goal reset and enable, alert queue (skip, pause, resume, clear), fire a test alert for a rule, enable, disable or toggle a page of a multi-page overlay, show a page, next, previous, first, last and auto-advance, end the session.

**Feedbacks:** timer state, Twitch live, session phase, goal complete or enabled, alert queue paused, music playing, overlay page enabled, showing now, and auto-advance on.

**Variables:** session phase, viewers, stream title and category, now-playing track, alert queue, plus per-timer time and state and per-goal percent and progress, and the current page of each multi-page overlay. Timers and goals appear automatically.
