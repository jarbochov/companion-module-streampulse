## StreamPulse

Controls a running [StreamPulse](https://github.com/jarbochov/StreamPulse) server.

**Config:** host and port of the StreamPulse server (default `localhost:3000`).

**Actions:** timer control (start, pause, resume, reset, add or subtract time, overlay visibility), goal reset and enable, alert queue (skip, pause, resume, clear), fire a test alert for a rule, enable, disable or toggle a page of a multi-page overlay, show a page, next, previous, first, last and auto-advance, slideshow next, previous, play, pause and toggle, show, hide or toggle any whole overlay (credits, goals, timers, music, custom overlays), music overlay show, hide or toggle, pin the last chat message, mark a clip moment, replay the last alert, start or end a session.

**Feedbacks:** timer state, Twitch live, session phase, goal complete or enabled, alert queue paused, music playing, overlay shown, music overlay visible, slideshow playing, paused or open, overlay page enabled, showing now, and auto-advance on.

**Variables:** session phase, viewers, stream title and category, now-playing track, alert queue, plus per-timer time and state and per-goal percent and progress, the current page of each multi-page overlay, slideshow position and state, uptime, game details, music position, chat counts, and the latest follower, sub, gift, cheer, donation and raider. Slideshow state needs the overlay open in OBS or a browser. Timers and goals appear automatically.
