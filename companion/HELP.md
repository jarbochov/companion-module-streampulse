## StreamPulse

Controls a running [StreamPulse](https://github.com/jarbochov/StreamPulse) server.

**Config:** host and port of the StreamPulse server (default `localhost:3000`).

**Actions:** All commands are organized with clear category prefixes for fast, intuitive searching in Companion (e.g. searching "Alert", "Overlay", "Tier", "Poll", "Versus", "Tournament", "Randomizer", "Chat", "Variable", "Timer", "Goal", "Session").

- **Alerts:** Queue control (skip, pause, resume, clear), mute or unmute alert display (toggle), replay last alert, fire test alert for a rule, simulate live stream events (follow, sub, resub, gift, bits, donation, raid, channel points), and test external webhooks or Companion button presses directly.
- **Overlay & Pages:** Navigate multi-page overlays (next, prev, first, last, auto-advance), show page by name, enable/disable pages, show/hide entire overlays, video playback control (play, pause, toggle, restart, stop, mute, unmute), cutout punchthrough hole control (toggle, punch, fill), slideshow controls (next, prev, play, pause, toggle), and music overlay toggle.
- **Tier Maker (Tier List Studio):** Start voting on an item (auto-selects next unranked item if omitted, configurable duration and consensus mode), lock voting (closes chat voting to freeze votes while keeping consensus displayed for discussion), end vote & place into consensus tier (or discard), cancel active vote, reset all placed items back to unranked queue, and load saved tier list template presets.
- **Polls & Tournaments:** Start polls from saved presets or custom questions (with blind voting and 2x sub multiplier), end/crown winner, extend (+seconds), or cancel active polls; tournament bracket actions to score entrant game wins or round pips, confirm & advance match winners, cycle or pin/unpin active matches, toggle live bracket highlight glow, reset/rollback matches, and launch Poll Tournament match votes; bracket camera focus and section view controls.
- **Randomizer Studio:** Spin the randomizer wheel, vertical roller, or physical card deck with configurable duration, auto-hide, phrases, and winner text; toggle or force elimination on/off; restore removed choices.
- **Chat Bot:** Turn bot on/off/toggle, send chat messages, run bot commands or triggers with arguments, send quotes to chat.
- **Variables & Counters:** Increment/decrement/reset counters, set variable values, roll list or topic.
- **Timers & Goals:** Start, pause, resume, reset, add/subtract time, toggle timer overlay visibility, reset/enable/disable goals.
- **Production & Server:** Mark clip candidate moments, pin chat messages as highlights, start/end/archive sessions, reset chat data, restart/stop StreamPulse server.

**Tier Maker Studio:** actions to start votes on specific or next unranked items, freeze/lock voting, lock & place consensus into tier, cancel votes, reset item placements, and load template presets; variables for `tier_voting` ('yes' / 'no'), `tier_vote_status` ('idle', 'active', 'locked'), `tier_item` (current item name), `tier_votes` (total votes cast), `tier_consensus` (winning tier label, e.g. S, A, B), `tier_agreement` (consensus percentage, e.g. 75%), `tier_time` (remaining seconds or 'open'), and `tier_title` (list title); feedbacks for `tier_voting_active`, `tier_vote_locked`, and `tier_consensus_tier` (lights up when leading consensus matches a target tier); ready-to-use button presets for starting votes, locking votes, placing consensus, and cancelling votes.

**Feedbacks:** StreamPulse server running (use Invert to flag when it is down), randomizer actively spinning (lights button while wheel or roller spins on stream), tier list voting actively running or locked, tier consensus tier match, timer state, Twitch live, session phase, goal complete or enabled, alert queue paused, alerts muted, music playing, overlay shown, music overlay visible, slideshow playing, paused or open, overlay page enabled, showing now, and auto-advance on.

**Versus & Speedrun Studio:** actions for game scores (`+/-`) and round scores (`+/-`), clock/race control (start, pause, reset, sync start all runners, per-runner finish/toggle/reset for up to 4 runners, speedrun timer display mode `finish` [Main Clock Only — Reveal on Finish + Delta] vs `always` [Always Show Live Runner Timers], None), swap sides, reset scores, queue navigation, preset loading, and Save Progress; variables `matchup_title`, `matchup_c1_score`, `matchup_c1_rounds`, `matchup_c1_time`, `matchup_c1_delta`, `matchup_c1_place`, `matchup_clock`, `matchup_runner_timers_mode`, and more; feedbacks for clock running, runner finished (1–4), and win requirement met.

**Polls & Tournaments:** actions to start polls from saved presets or custom question/choices (with blind voting and 2x sub multiplier), end/crown winner, extend (+seconds), or cancel active polls; tournament bracket actions to score entrant game wins or round pips, confirm & advance match winners, cycle or pin/unpin active matches, toggle live bracket highlight glow, reset/rollback matches, and launch Poll Tournament match votes; variables for `poll_active`, `poll_title`, `poll_total_votes`, `poll_remaining`, `poll_leader`, `poll_winner`, `tournament_title`, `tournament_round`, `tournament_e1_name`, `tournament_e1_score`, `tournament_e1_rounds`, `tournament_e2_name`, `tournament_e2_score`, `tournament_e2_rounds`, `tournament_pending_winner`, `tournament_champion`; feedbacks for `poll_active`, `tournament_active`, and `tournament_win_ready` (lights up when an entrant meets the match win target and is ready to advance).

Per-runner finish, toggle, and reset use an explicit zero-based API index for the selected Runner 1–4. Existing buttons retain their runner selection; no reconfiguration is required.

**Presets:** `Spin Randomizer (Wheel / Roller / Deck)` shows the last used mode and duration on the button; `Draw Randomizer Card` is a ready-to-use deck draw button. Both support Studio/overlay inheritance and explicit duration/auto-hide overrides.

### Poll Tournament templates and saved progress

- **Save active bracket as template** stores entrants and settings via `POST /api/polls/tournament/presets` with `{name, fromActive: true}`. **Save progress checkpoint** uses `POST /api/polls/tournament/checkpoints` with `{name}`. Names are optional and accept Companion variables. Both are safe during a running vote and do not change it.
- **Create fresh bracket from template** accepts a template ID. Get IDs from `GET /api/polls/tournament/presets` on your StreamPulse server (open the URL in a browser), then paste the chosen `presets[].id` into the action. On press, Companion fetches the current template and sends only its entrants/settings to `POST /api/polls/tournament/create`; scores, bracket identity and prior progress are not reused.
- **Load saved bracket / checkpoint** accepts a `history[].id` from `GET /api/polls/tournament/history`. Entries include `savedName`, `savedAt`, and `isCheckpoint` to identify saved progress. Companion calls `POST /api/polls/tournament/history/restore` with `{id}`.
- Load/create actions do nothing unless **I confirm this button may replace the current poll bracket** is checked in their configuration. This is a persistent button authorization, not a confirmation dialog on each press. Use dedicated, clearly labeled buttons. The server blocks restore during **any** active vote and blocks fresh creation during a linked bracket vote; rejected requests are logged in Companion.
- Loading replaces the current bracket and archives a replaced started bracket. Completed brackets stay completed; unfinished matches restart voting when launched. Individual voters are never restored.

IDs accept Companion variables. Library lists are deliberately not background-polled: fetch IDs when configuring buttons, and update the ID if its saved entry is removed. Saving new entries does not automatically select them on other buttons.

**Variables:** server online, uptime and start time, randomizer winner (`randomizer_last_winner`), randomizer preset (`randomizer_last_preset`), randomizer mode (`randomizer_last_mode`), last spin duration in seconds (`randomizer_last_duration`), randomizer spinning state (`randomizer_spinning`), choices left in the pool (`randomizer_remaining`), choices removed (`randomizer_removed`), elimination mode (`randomizer_elimination`), session phase, viewers, stream title and category, now-playing track, alert queue (including paused and muted), plus per-timer time and state and per-goal percent and progress, the current page of each multi-page overlay, slideshow position and state, uptime, game details, music position, chat counts, and the latest follower, sub, gift, cheer, donation and raider (with cheer and donation amounts and raid viewer count). Also last chatter and top chatter for the last 5/10/15/30/60 minutes, top hashtags, game developer and rating, clip candidates waiting, session and lifetime followers, subscribers, gift subs, bits and donations, milestones & streaks (current stream number, lifetime broadcast hours/time, daily and weekly streaks, lifetime unique chatters, lifetime messages, next stream and broadcast hour goals), Game Plan (playing now, next scheduled, counts) and weather (temperature, condition, icon, high/low, wind; needs weather enabled in StreamPulse). Slideshow state needs the overlay open in OBS or a browser. Timers and goals appear automatically.
